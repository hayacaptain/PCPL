# **1. Описание задания** 

Разработать три консольные программы на языке Python для решения биквадратного уравнения вида A·x + B·x² + C = 0. Программы должны⁴ вычислять дискриминант квадратного уравнения относительно y = x² и выводить только действительные корни. 

Необходимо реализовать решение в трёх парадигмах: процедурной (с использованием функций и def), объектно-ориентированной (с использованием класса) и функциональной (с использованием сопоставления с образцом match/case). Коэффициенты A, B и C могут передаваться через командную строку. Если параметр отсутствует или некорректен, он запрашивается с клавиатуры повторно до получения действительного числа. 

Для биквадратного уравнения вводится замена y = x². Тогда получается квадратное уравнение A·y² + B·y + C = 0 с дискриминантом D = B² − 4AC. Для каждого найденного y ≥ 0 вычисляются действительные значения x = ±√y; при y = 0 корень равен x = 0.

def solve_with_pattern(a, b, c):
    """Solve using structural pattern matching."""
    match a, b, c:
        case (a, b, c) if a == 0:
            raise ValueError("Коэффициент A не должен быть равен нулю.")
