# Лабораторная работа №4 — Strategy и модульное тестирование

## Предметная область
Расчёт стоимости заказа в интернет-магазине с разными видами скидок.

## Структура
- `shop.py` — реализация Strategy и демонстрационный запуск.
- `tests/test_shop.py` — модульные тесты, параметризация и Mock.
- `features/discount.feature` — сценарии BDD на языке Gherkin.
- `tests/test_bdd.py` — автоматизация BDD-сценариев через pytest-bdd.

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate       # Linux/macOS
# .venv\\Scripts\\activate      # Windows
pip install -r requirements.txt
python shop.py
pytest -v
```

## Ожидаемый вывод программы
```text
Без скидки: 1000.00 руб.
Скидка 10%: 900.00 руб.
Скидка 150 руб.: 850.00 руб.
```

TDD отражён в наборе модульных тестов: сначала формулируются проверки ожидаемого поведения, затем реализация обеспечивает их прохождение. Для демонстрации полного цикла TDD тесты можно запускать до и после изменения реализации.
